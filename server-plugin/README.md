# ปลั๊กอินพ็อกกี้ฝั่งเซิร์ฟเวอร์

ตัวเสริมสำหรับคนที่รันเซิร์ฟเวอร์ SillyTavern เอง ทำให้พ็อกกี้เชื่อม Google Drive เองตลอด ไม่ต้องคลิกทุกครั้งที่เปิดหน้า

วิธีติดตั้ง: ก๊อปโฟลเดอร์ `pocky-chat-vault` (ข้าง ๆ ไฟล์นี้) ไปวางที่ `SillyTavern/plugins/` แล้วทำตามหัวข้อ **🔌 ตัวเสริม** ใน README หลักของโปรเจกต์

⚠️ เซิร์ฟเวอร์ที่เปิดเข้าจากอินเทอร์เน็ตได้ ต้องตั้งรหัสผ่าน SillyTavern (`basicAuthMode`) ก่อนติดตั้งปลั๊กอินนี้
