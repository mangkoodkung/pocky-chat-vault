# Pocky chat vault

ส่วนเสริม SillyTavern แบบ Mobile-first สำหรับสำรองแชทเป็น `.jsonl` มาตรฐานหรือ `.cvault` ที่เข้ารหัสและรวมสื่อได้ โดยควบคุมจากแมวลอยบนหน้าจอ และส่งสำเนาจากเบราว์เซอร์ของผู้ใช้ไปยัง Google Drive ของผู้ใช้โดยตรง

---

# 📥 วิธีติดตั้งและใช้งาน (สำหรับผู้ใช้)

> อ่านทีละขั้น ทำตามได้เลย · ถ้าจะใช้แค่เก็บในเครื่อง ทำแค่ **ขั้นที่ 1–2** พอ ไม่ต้องยุ่งกับ Google

## ขั้นที่ 1 · ติดตั้งส่วนเสริม

เลือกวิธีใดวิธีหนึ่ง:

### วิธี A — ผ่านตัวติดตั้งของ SillyTavern (ง่ายสุด แนะนำ)

1. เปิด SillyTavern แล้วกดไอคอน **Extensions** (รูปต่อบล็อก) ที่แถบด้านบน
2. กดปุ่ม **Install extension**
3. วางลิงก์นี้ลงในช่อง:
   ```
   https://github.com/mangkoodkung/pocky-chat-vault
   ```
4. กด **Install** แล้วรอสักครู่ · ส่วนเสริมจะไปโผล่ในรายการ Extensions

### วิธี B — ติดตั้งด้วยมือ (กรณีตัวติดตั้งใช้ไม่ได้)

1. บนหน้า GitHub กด **Code → Download ZIP** แล้วแตกไฟล์ (หรือใช้ `git clone`)
2. ก๊อปโฟลเดอร์ `pocky-chat-vault` ทั้งโฟลเดอร์ไปวางที่:
   ```
   SillyTavern/data/<ชื่อผู้ใช้ของคุณ>/extensions/
   ```
   (ถ้าลงให้ทุกคนในเครื่อง ใช้ตำแหน่ง third-party extension ที่ SillyTavern ระบบนั้นกำหนด)
3. รีเฟรชหน้า SillyTavern

## ขั้นที่ 2 · เริ่มใช้แบบเก็บในเครื่อง (ไม่ต้องตั้ง Google)

1. จะเห็น **แมวพ็อกกี้** 🐱 ลอยอยู่ที่มุมจอ — กดที่ตัวแมวเพื่อเปิดเมนู
2. ไปแท็บ **ตั้งค่า** → เลือกโหมดสำรอง (แนะนำ **"สมดุล — เมื่อคำตอบเสร็จ"**)
3. เสร็จแล้ว! ทุกครั้งที่คุยแชท พ็อกกี้จะเก็บจุดย้อนเวลาในเครื่องให้อัตโนมัติ
4. อยากกู้คืน → แท็บ **กู้คืน** → **ไทม์แมชชีนพ็อกกี้** → เลือกจุดที่ต้องการ

ระดับนี้ไม่ต้องเชื่อมเน็ตหรือ Google อะไรเลย ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้น

## ขั้นที่ 3 · (ไม่บังคับ) เปิดสำรองขึ้น Google Drive

ถ้าอยากให้ข้อมูลไปอยู่บน Drive ด้วย (กันเครื่องพัง/ล้างเบราว์เซอร์) ต้องสร้าง **Google OAuth Client ID ของตัวเอง** ครั้งเดียว ทำตามนี้:

### 3.1 สร้างโปรเจกต์ Google Cloud

1. เข้า <https://console.cloud.google.com/> แล้วล็อกอินบัญชี Google ที่จะใช้
2. กดเมนูเลือกโปรเจกต์ (มุมบนซ้าย ข้าง ๆ โลโก้) → **New Project** → ตั้งชื่อ เช่น `Chat Vault` → **Create**

### 3.2 เปิด Google Drive API

3. เมนูซ้าย → **APIs & Services → Library**
4. ค้นหา **Google Drive API** → กดเข้าไป → กด **Enable**

### 3.3 ตั้ง OAuth consent screen

5. เมนูซ้าย → **APIs & Services → OAuth consent screen**
6. เลือก **External** → **Create**
7. กรอกชื่อแอป (เช่น `Chat Vault`) และอีเมลติดต่อ → **Save and Continue** ไปจนจบ
8. หน้า **Test users** → กด **Add users** ใส่อีเมลบัญชีที่จะใช้สำรอง (ถ้าไม่กด Publish จะเชื่อมได้เฉพาะอีเมลที่เพิ่มเป็น test user)

### 3.4 สร้าง OAuth Client ID

9. เมนูซ้าย → **APIs & Services → Credentials** (หน้าใหม่ของ Google เปลี่ยนชื่อเป็น **Google Auth Platform → Clients** แล้ว ถ้าเห็นชื่อนี้คือถูกหน้าเดียวกัน)
10. กด **Create Credentials → OAuth client ID** (หน้าใหม่คือปุ่ม **Create client**)
11. **Application type** เลือก **Web application** → ตั้งชื่อ
12. หัวข้อ **Authorized JavaScript origins** → กด **Add URI** → ใส่ origin ของหน้า SillyTavern ของคุณ **ให้ตรงเป๊ะทุกตัวอักษร** เช่น
    - `https://st.example.com` (ถ้าเปิดผ่านโดเมน)
    - `http://localhost:8000` (ถ้าเปิดในเครื่อง)

    > ⚠️ **จุดพลาดที่เจอบ่อย:** ห้ามใส่ `/` หรือ path ต่อท้าย · `localhost` กับ `127.0.0.1` ถือเป็นคนละ origin · พอร์ตต้องตรง · `http` กับ `https` ต่างกัน
13. **ถ้าจะใช้บน iPhone/iPad** → หัวข้อ **Authorized redirect URIs** → กด **Add URI** → ใส่ **URL ของหน้า SillyTavern แบบเต็ม** เช่น
    - `https://st.example.com/`
    - `http://localhost:8000/`

    > บน iOS หน้าต่างป๊อปอัปส่งสิทธิ์กลับมาไม่ได้ (ข้อจำกัดของ iOS เอง) พ็อกกี้จึงเปลี่ยนไปใช้วิธีพาไปหน้า Google แล้วเด้งกลับแทน ซึ่งต้องลงทะเบียนที่อยู่ขากลับไว้ก่อน · **ถ้าใช้แค่บนคอมข้ามข้อนี้ได้** · ค่าที่ต้องใส่ดูได้จาก **Extensions settings → Pocky chat vault** จะแสดงไว้ให้ตรงเป๊ะ
14. กด **Create** → จะได้ **Client ID** ที่ลงท้ายด้วย `.apps.googleusercontent.com` → ก๊อปไว้

### 3.5 ใส่ Client ID ใน SillyTavern

15. เปิด SillyTavern → **Extensions settings → Pocky chat vault** → วาง Client ID ที่ก๊อปมา
16. กดแมว → แท็บ **ตั้งค่า** → เปลี่ยนที่เก็บเป็น **Google Drive**
17. กดปุ่ม **ต่อบัญชี Google ให้พ็อกกี้** → เลือกบัญชี → อนุญาตสิทธิ์
18. การ์ดบัญชีขึ้นชื่ออีเมล = เชื่อมสำเร็จ 🎉 จากนี้พ็อกกี้จะส่งสำเนาขึ้น Drive ให้อัตโนมัติ

> Client ID เป็นข้อมูล**สาธารณะ** ใส่ใน settings ได้ปลอดภัย · แต่ **Client secret ไม่ต้องใช้และห้ามใส่** ที่ไหนทั้งสิ้น

# 🔄 อัปเดตรุ่นใหม่ (มีพ็อกกี้อยู่แล้ว)

อัปเดตแล้วการตั้งค่าเดิมอยู่ครบ ไม่ต้องตั้งใหม่ ไม่ต้องไปยุ่งกับ Google อีกรอบ

วิธีอัปเดต เลือกเอาทางใดทางหนึ่ง:

- ผ่าน SillyTavern: ไอคอน **Extensions → Manage extensions** → กดอัปเดตของ Pocky chat vault
- หรือโหลด ZIP จาก GitHub มาเอง: **ลบโฟลเดอร์เก่าทิ้ง แล้ววางโฟลเดอร์ใหม่แทนทั้งโฟลเดอร์** อย่าก๊อปทับแค่บางไฟล์ เพราะรุ่นใหม่มีไฟล์เพิ่ม ถ้าไฟล์ไม่ครบแมวจะไม่ขึ้นเลย (การตั้งค่าไม่หายนะ มันไม่ได้เก็บอยู่ในโฟลเดอร์นี้)

เสร็จแล้วรีเฟรชแรง ๆ หนึ่งที (**Ctrl+Shift+R**) กดที่แมวดูเลขรุ่น ถ้าเปลี่ยนแล้วคือเรียบร้อย

ของที่เปลี่ยนไปในรุ่นนี้ อ่านไว้นิดจะได้ไม่ตกใจ:

- เปิดหน้ามาพ็อกกี้จะยังไม่เชื่อม Google ทันที พอเราคลิกอะไรสักอย่างครั้งแรกถึงจะเชื่อมให้เอง บางทีมีหน้าต่างเด้งแวบแล้วปิดไปเอง อันนี้ปกติ ไม่ได้พัง
- ช่องโฟลเดอร์เปลี่ยนเป็นแบบรายการ เห็นเลยว่ามีโฟลเดอร์ไหนบ้าง อันไหนมีสำเนากี่ไฟล์ ถ้าเจอโฟลเดอร์ชื่อซ้ำ (ฝีมือบั๊กรุ่นเก่า ขอโทษด้วย) ให้เลือกอันที่ไฟล์เยอะสุดแล้วกด **ใช้โฟลเดอร์นี้** ส่วนอันที่ว่างเปล่ากด **เก็บกวาดโฟลเดอร์ว่าง** ได้เลย มันแค่ย้ายลงถังขยะ Drive กู้คืนได้ใน 30 วัน

# 🔌 ตัวเสริม: ให้พ็อกกี้เชื่อมเองตลอด ไม่ต้องคลิกเลย

ปกติหลังเปิดหน้า เราคลิกอะไรหนึ่งทีพ็อกกี้ถึงจะเชื่อม Google ให้ ถ้าอยากได้แบบ**เชื่อมเองทันทีทุกครั้ง ไม่ต้องคลิก มือถือก็ด้วย** ให้ติดตั้งปลั๊กอินเสริมตัวนี้

ใครติดตั้งได้: ต้องเป็นคนที่**รันเซิร์ฟเวอร์ SillyTavern เอง** แก้ไฟล์ตั้งค่ากับรีสตาร์ทได้ · ถ้าใช้เซิร์ฟเวอร์ของคนอื่น ข้ามส่วนนี้ไปเลย ใช้แบบปกติก็สะดวกอยู่แล้ว

> ⚠️ ข้อเดียวที่ห้ามพลาด: ถ้าเซิร์ฟเวอร์ของคุณเปิดเข้าจากอินเทอร์เน็ตได้ ต้องตั้งรหัสผ่านของ SillyTavern ก่อน (`basicAuthMode` ใน config.yaml) ไม่งั้นใครที่เปิดเว็บถึงก็หยิบสิทธิ์ Drive ของคุณไปใช้ได้

ทำตามนี้:

1. ใน ZIP ที่โหลดมา มีโฟลเดอร์ `server-plugin` อยู่ · ก๊อปโฟลเดอร์ `pocky-chat-vault` ที่อยู่ข้างในไปวางที่ `SillyTavern/plugins/`
2. เปิดไฟล์ `config.yaml` ของ SillyTavern หาบรรทัด `enableServerPlugins` แก้เป็น `true` แล้วรีสตาร์ทเซิร์ฟเวอร์
3. ไปหน้า Google Cloud เดิมของคุณ (Credentials → Client ที่เคยสร้าง):
   - กด **Add URI** ใน **Authorized redirect URIs** ใส่ค่าที่พ็อกกี้แสดงไว้ในหน้า Extensions settings (ลงท้ายด้วย `/api/plugins/pocky-vault/auth/callback`)
   - กด **Add secret** แล้วก๊อปค่า `GOCSPX-...` ที่ได้ทันที มันโชว์ครั้งเดียว
4. กลับมาที่ **Extensions settings → Pocky chat vault** จะเห็นช่องของปลั๊กอินโผล่มา วาง secret แล้วกด **บันทึกลงปลั๊กอิน**
5. กด **เชื่อมบัญชี Google** เลือกบัญชี กดอนุญาต เสร็จแล้ว

จากนี้เปิดกี่ครั้งก็เชื่อมเองตลอด ทั้งคอมทั้งมือถือ

หมายเหตุ: ถ้าหน้า consent screen ของ Google ยังเป็นโหมด Testing สิทธิ์จะหมดอายุทุก 7 วัน ต้องกดเชื่อมใหม่หนึ่งที · ไม่อยากเจอก็กด **Publish app** ในหน้านั้น (แอปแบบนี้ไม่ต้องผ่านรีวิว)

## แก้ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
| --- | --- |
| กดเชื่อมแล้วหน้าต่าง Google ไม่เด้ง | ปลดบล็อกป๊อปอัปของเบราว์เซอร์สำหรับหน้านี้ |
| ขึ้น error `redirect_uri_mismatch` / origin | origin ใน Google Cloud ไม่ตรงกับหน้าจริง เช็ก `http`/`https`, `localhost` vs `127.0.0.1`, พอร์ต, และห้ามมี `/` ท้าย |
| `Access blocked · app not verified` | เพิ่มอีเมลตัวเองใน **Test users** หรือกด **Publish app** ในหน้า consent screen |
| บน iPhone/iPad กดเชื่อมแล้วเด้งกลับมาแต่ไม่ติด | ยังไม่ได้ใส่ **Authorized redirect URI** (ข้อ 13) · ต้องตรงกับค่าที่แสดงใน Extensions settings ทุกตัวอักษร รวม `/` ปิดท้าย |
| ขึ้นว่า "สิทธิ์ที่ได้กลับมาไม่ใช่ของแอปนี้" | ระบบปฏิเสธสิทธิ์ที่ไม่ได้ออกให้ Client ID ของคุณ เพื่อความปลอดภัย · กดเชื่อมใหม่จากในแอปเท่านั้น อย่ากดลิงก์เชื่อมที่คนอื่นส่งมา |
| เชื่อมได้แต่ไม่เห็นไฟล์บน Drive | เปิดโฟลเดอร์ `Chat Vault` บน Drive · สิทธิ์ `drive.file` ทำให้แอปเห็นเฉพาะไฟล์ที่มันสร้าง ไม่ใช่ Drive ทั้งบัญชี |
| เปิดหน้ามาแล้วยังไม่เชื่อม ต้องคลิกก่อนถึงจะเชื่อม / มีหน้าต่างเด้งแวบตอนคลิกแรก | เรื่องปกติของรุ่นใหม่ พ็อกกี้รอให้เราคลิกครั้งแรกแล้วค่อยเชื่อมให้เอง ไม่ต้องทำอะไรเพิ่ม |
| อัปเดตแล้วแมวหายไปเลย | ไฟล์ไม่ครบ ให้ลบโฟลเดอร์เก่าแล้ววางใหม่ทั้งโฟลเดอร์ เสร็จแล้วกด Ctrl+Shift+R |

**สรุประดับความยาก:** เก็บในเครื่อง = ง่ายมาก (2 นาที) · เชื่อม Google Drive = ตั้งครั้งแรกใช้เวลา ~10 นาที ยากตรง Google Cloud แต่ทำครั้งเดียวจบ
