# Pocky chat vault

ส่วนเสริม SillyTavern แบบ Mobile-first สำหรับสำรองแชทเป็น `.jsonl` มาตรฐานหรือ `.cvault` ที่เข้ารหัสและรวมสื่อได้ โดยควบคุมจากแมวลอยบนหน้าจอ และส่งสำเนาจากเบราว์เซอร์ของผู้ใช้ไปยัง Google Drive ของผู้ใช้โดยตรง

---

# 📥 วิธีติดตั้งและใช้งาน (สำหรับผู้ใช้)

> อ่านทีละขั้น ทำตามได้เลย · ถ้าจะใช้แค่เก็บในเครื่อง ทำแค่ **ขั้นที่ 1–2** พอ ไม่ต้องยุ่งกับ Google

## ขั้นที่ 1 · ติดตั้งส่วนเสริม

เลือกวิธีใดวิธีหนึ่ง:

### วิธี A — ผ่านตัวติดตั้งของ SillyTavern (ง่ายสุด แนะนำ)

1. เปิด SillyTavern แล้วกดไอคอน **Extensions** (รูปต่อบล็อก) ที่แถบด้านบน
2. กดปุ่ม **Install extension**
3. วางลิงก์นี้ลงในช่อง:
   ```
   https://github.com/mangkoodkung/pocky-chat-vault
   ```
4. กด **Install** แล้วรอสักครู่ · ส่วนเสริมจะไปโผล่ในรายการ Extensions

### วิธี B — ติดตั้งด้วยมือ (กรณีตัวติดตั้งใช้ไม่ได้)

1. บนหน้า GitHub กด **Code → Download ZIP** แล้วแตกไฟล์ (หรือใช้ `git clone`)
2. ก๊อปโฟลเดอร์ `pocky-chat-vault` ทั้งโฟลเดอร์ไปวางที่:
   ```
   SillyTavern/data/<ชื่อผู้ใช้ของคุณ>/extensions/
   ```
   (ถ้าลงให้ทุกคนในเครื่อง ใช้ตำแหน่ง third-party extension ที่ SillyTavern ระบบนั้นกำหนด)
3. รีเฟรชหน้า SillyTavern

## ขั้นที่ 2 · เริ่มใช้แบบเก็บในเครื่อง (ไม่ต้องตั้ง Google)

1. จะเห็น **แมวพ็อกกี้** 🐱 ลอยอยู่ที่มุมจอ — กดที่ตัวแมวเพื่อเปิดเมนู
2. ไปแท็บ **ตั้งค่า** → เลือกโหมดสำรอง (แนะนำ **"สมดุล — เมื่อคำตอบเสร็จ"**)
3. เสร็จแล้ว! ทุกครั้งที่คุยแชท พ็อกกี้จะเก็บจุดย้อนเวลาในเครื่องให้อัตโนมัติ
4. อยากกู้คืน → แท็บ **กู้คืน** → **ไทม์แมชชีนพ็อกกี้** → เลือกจุดที่ต้องการ

ระดับนี้ไม่ต้องเชื่อมเน็ตหรือ Google อะไรเลย ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้น

## ขั้นที่ 3 · (ไม่บังคับ) เปิดสำรองขึ้น Google Drive

ถ้าอยากให้ข้อมูลไปอยู่บน Drive ด้วย (กันเครื่องพัง/ล้างเบราว์เซอร์) ต้องสร้าง **Google OAuth Client ID ของตัวเอง** ครั้งเดียว ทำตามนี้:

### 3.1 สร้างโปรเจกต์ Google Cloud

1. เข้า <https://console.cloud.google.com/> แล้วล็อกอินบัญชี Google ที่จะใช้
2. กดเมนูเลือกโปรเจกต์ (มุมบนซ้าย ข้าง ๆ โลโก้) → **New Project** → ตั้งชื่อ เช่น `Chat Vault` → **Create**

### 3.2 เปิด Google Drive API

3. เมนูซ้าย → **APIs & Services → Library**
4. ค้นหา **Google Drive API** → กดเข้าไป → กด **Enable**

### 3.3 ตั้ง OAuth consent screen

5. เมนูซ้าย → **APIs & Services → OAuth consent screen**
6. เลือก **External** → **Create**
7. กรอกชื่อแอป (เช่น `Chat Vault`) และอีเมลติดต่อ → **Save and Continue** ไปจนจบ
8. หน้า **Test users** → กด **Add users** ใส่อีเมลบัญชีที่จะใช้สำรอง (ถ้าไม่กด Publish จะเชื่อมได้เฉพาะอีเมลที่เพิ่มเป็น test user)

### 3.4 สร้าง OAuth Client ID

9. เมนูซ้าย → **APIs & Services → Credentials**
10. กด **Create Credentials → OAuth client ID**
11. **Application type** เลือก **Web application** → ตั้งชื่อ
12. หัวข้อ **Authorized JavaScript origins** → กด **Add URI** → ใส่ origin ของหน้า SillyTavern ของคุณ **ให้ตรงเป๊ะทุกตัวอักษร** เช่น
    - `https://st.example.com` (ถ้าเปิดผ่านโดเมน)
    - `http://localhost:8000` (ถ้าเปิดในเครื่อง)

    > ⚠️ **จุดพลาดที่เจอบ่อย:** ห้ามใส่ `/` หรือ path ต่อท้าย · `localhost` กับ `127.0.0.1` ถือเป็นคนละ origin · พอร์ตต้องตรง · `http` กับ `https` ต่างกัน
13. กด **Create** → จะได้ **Client ID** ที่ลงท้ายด้วย `.apps.googleusercontent.com` → ก๊อปไว้

### 3.5 ใส่ Client ID ใน SillyTavern

14. เปิด SillyTavern → **Extensions settings → Pocky chat vault** → วาง Client ID ที่ก๊อปมา
15. กดแมว → แท็บ **ตั้งค่า** → เปลี่ยนที่เก็บเป็น **Google Drive**
16. กดปุ่ม **ต่อบัญชี Google ให้พ็อกกี้** → เลือกบัญชี → อนุญาตสิทธิ์
17. การ์ดบัญชีขึ้นชื่ออีเมล = เชื่อมสำเร็จ 🎉 จากนี้พ็อกกี้จะส่งสำเนาขึ้น Drive ให้อัตโนมัติ

> Client ID เป็นข้อมูล**สาธารณะ** ใส่ใน settings ได้ปลอดภัย · แต่ **Client secret ไม่ต้องใช้และห้ามใส่** ที่ไหนทั้งสิ้น

## แก้ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
| --- | --- |
| กดเชื่อมแล้วหน้าต่าง Google ไม่เด้ง | ปลดบล็อกป๊อปอัปของเบราว์เซอร์สำหรับหน้านี้ |
| ขึ้น error `redirect_uri_mismatch` / origin | origin ใน Google Cloud ไม่ตรงกับหน้าจริง เช็ก `http`/`https`, `localhost` vs `127.0.0.1`, พอร์ต, และห้ามมี `/` ท้าย |
| `Access blocked · app not verified` | เพิ่มอีเมลตัวเองใน **Test users** หรือกด **Publish app** ในหน้า consent screen |
| เชื่อมได้แต่ไม่เห็นไฟล์บน Drive | เปิดโฟลเดอร์ `Chat Vault` บน Drive · สิทธิ์ `drive.file` ทำให้แอปเห็นเฉพาะไฟล์ที่มันสร้าง ไม่ใช่ Drive ทั้งบัญชี |

**สรุประดับความยาก:** เก็บในเครื่อง = ง่ายมาก (2 นาที) · เชื่อม Google Drive = ตั้งครั้งแรกใช้เวลา ~10 นาที ยากตรง Google Cloud แต่ทำครั้งเดียวจบ
